Long-only cbBTC/USDC minute bot for the bars-replay harness: EMA trend filter with a 240-bar Donchian breakout, a range-exhaustion leg for quiet phases, volatility gating, trailing stops and a drawdown guard. It answers the harness `hello`, then one `batch` per bar with at most 16 `orders`, staying deterministic across both graded runs.

## Run it

node main.ts
